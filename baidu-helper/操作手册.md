# 百度网盘分享链接助手操作手册

## 1. 工具用途

百度网盘分享链接助手用于批量扫描百度网盘中的一个或多个目录，为目录内的每个文件分别创建带提取码的分享链接，并将文件名和链接导出为 Excel 工作簿。

适用场景：整理资料分享、为文件夹中的大量文件逐个生成链接、将链接清单交付给其他人使用。

## 2. 使用前准备

- 操作系统：Windows 10 或 Windows 11，64 位。
- 网络：能够访问百度网盘。
- 账号：可正常登录百度网盘的账号。
- 浏览器组件：首次打开“扫码 / 网页登录”窗口时，如提示缺少 WebView2 Runtime，请安装 Microsoft Edge WebView2 Runtime 后重试。
- 建议：确认待处理文件没有违反百度网盘规则，并避免在短时间内对大量文件重复创建分享，以免触发平台限制。

## 3. 安装与启动

1. 运行安装程序 `百度网盘分享链接助手安装程序.exe`。
2. 在安装窗口选择安装目录；默认位置为当前用户的本地应用程序目录。
3. 单击“开始安装”。安装完成后，程序会创建桌面快捷方式并自动启动。
4. 后续可通过桌面上的“百度网盘分享链接助手”快捷方式启动程序。

程序卸载后会删除安装目录和桌面快捷方式。已导出的 Excel 文件不会随卸载程序自动删除。

## 4. 首次设置与登录

1. 在左侧导航中打开“设置”。
2. 在“百度网盘登录”区域单击“扫码 / 网页登录”。
3. 在弹出的百度网盘页面中完成登录；登录后窗口会自动关闭，程序会保存当前登录会话。
4. 返回首页，登录状态显示“已登录”后即可创建任务。
5. 在“默认分享密码”中设置提取码。提取码必须是 **4 位英文字符或数字**，例如 `a123`、`6666`。
6. 在“导出设置”中选择默认导出目录；按需勾选“导出完成后自动打开 Excel 文件”。
7. 单击“保存全部设置”。

说明：登录会话和设置保存在程序安装目录下的 `data` 文件夹中，其中配置文件使用 Windows 当前用户的数据保护机制加密。切换 Windows 用户、清理程序数据或百度网盘会话失效后，需要重新登录。

## 5. 创建批量分享任务

### 5.1 选择网盘目录

1. 打开左侧“分享任务”。
2. 单击“浏览目录”。
3. 在目录选择窗口中双击文件夹进入下一级，使用“上一层”返回上级目录。
4. 选中要处理的文件夹后，单击“选择所选目录”。

可使用 Ctrl 或 Shift 一次选择多个目录。程序会对每个选定目录进行递归扫描，包含其下级目录中的文件；文件夹本身不会生成分享链接。

### 5.2 启动任务

1. 确认任务页显示的网盘目录正确。
2. 单击“开始”。
3. 程序先扫描目录，再为扫描到的每个文件创建独立分享链接。
4. 在“任务进度”和“实时日志”区域查看处理状态、已处理数量、成功数量和失败数量。

任务完成后，程序会在导出目录创建 Excel 文件。文件名默认取所选目录中最后一个路径段的名称；选择多个目录时，该名称可能来自最后一个选定目录。若目标文件已存在，程序会覆盖它。

## 6. 暂停、继续与丢弃

- **暂停**：单击“暂停”后，正在处理的文件会先完成；其余文件会在下一个文件处理边界等待。
- **继续**：暂停后单击“继续”，任务将从等待处继续执行。
- **丢弃**：仅在任务已暂停时可用。单击后会取消本次任务，不导出本次任务的 Excel，也不会写入历史导出记录。

不要在任务运行时直接关闭程序。若需要停止任务，请先暂停，再使用“丢弃”。

## 7. 查看和使用导出结果

在左侧“历史记录”中可查看每次成功完成的导出任务，包括导出时间、源目录、文件数量、成功数和失败数。

- 单击“打开 Excel”可打开对应的导出文件。
- 单击“删除”只会删除该条历史记录，**不会删除 Excel 文件**。

导出的 Excel 包含一个名为“分享链接”的工作表：

| 列 | 内容 |
| --- | --- |
| 文件名 | 原文件名，自动移除最后一个扩展名。例如 `archive.tar.gz` 导出为 `archive.tar`。 |
| 分享链接 | 该文件的分享地址，末尾包含 `pwd=提取码` 参数，便于复制后直接使用。 |

创建失败的文件仍会保留在表中，但分享链接单元格为空。请结合任务日志确认失败原因并重新创建任务。

## 8. 常见问题

### 提示“请先登录百度网盘”

进入“设置”，使用“扫码 / 网页登录”重新完成登录，并保存设置。若刚刚登录仍无法选择目录，可单击主窗口右上角“刷新”更新登录状态。

### 浏览目录失败或提示未获取到目录

确认网页登录已完成、网络可访问百度网盘，并重新打开目录选择窗口。若百度网盘登录状态已过期，请重新登录。

### 提示默认分享密码不正确

打开“设置”，将默认分享密码改为恰好 4 位的英文字母或数字，然后保存。例如 `a123`、`AB12`、`6666`。空密码或包含空格、中文、符号的密码不能用于创建任务。

### 个别文件创建失败

先查看任务日志中的错误信息。常见原因包括网络中断、登录会话过期、百度网盘接口返回限制或该文件不允许分享。恢复网络或重新登录后，可重新选择目录执行任务；程序会重新为文件发起创建请求。

### Excel 没有自动打开

在“设置”中勾选“导出完成后自动打开 Excel 文件”。即使未自动打开，也可以在“历史记录”中单击“打开 Excel”，或直接前往设置的导出目录打开文件。

### 程序异常退出

程序日志位于安装目录下的 `data\logs` 文件夹，按天生成。重新启动后请先检查登录状态；如问题持续，请保留相关日志和操作时间，以便排查。

## 9. 数据与安全说明

- 程序需要保存百度网盘网页登录会话，才能读取目录和创建分享链接。
- 会话配置只适用于保存它的 Windows 用户；请勿将程序的 `data` 目录提供给他人。
- 导出的 Excel 包含可访问文件的分享链接和提取码信息，应按文件内容的敏感级别妥善保管和分发。
- 登出可在首页单击“退出当前登录”；该操作会清除本地保存的 Cookie、BDUSS、STOKEN 和访问令牌。

## 10. 快速操作清单

1. 安装并启动程序。
2. 设置中完成网页登录，设置 4 位默认分享密码和导出目录。
3. 在“分享任务”中选择一个或多个网盘目录。
4. 单击“开始”，等待扫描、链接创建和 Excel 导出完成。
5. 在“历史记录”中打开 Excel，检查成功数、失败数和链接内容。
